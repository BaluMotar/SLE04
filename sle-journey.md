# Short summary of my SLE journey

| SLE | Focus | What I did |
| --- | --- | --- |
| SLE-1 | Code | Built a maze-search system using BFS and DFS and documented it on GitHub. |
| SLE-2 | Performance | Profiled the algorithms and compared their execution behaviour (average search time and nodes reported). |

| SLE-4 | Decision + viva | Recorded the decision (ADR-0001) to prefer BFS for shortest paths in an unweighted maze, keeping DFS for comparison. |

**One line:** SLE-1 = Code, SLE-2 = Performance, SLE-3 = Architecture, SLE-4 = Decision + Viva.
